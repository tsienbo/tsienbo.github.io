☁️ 跨端进度同步（PC ↔ 手机实时同步）

方式一：GitHub Gist 自动云同步（推荐 · 配置一次永久自动同步）

1. 点击打开 GitHub 生成 Token 页面 ↗（仅需勾选 gist 权限，Expiration 选 No expiration），生成后复制以 ghp_ 开头的 Token。
2. 在电脑和手机网页各粘贴一次该 Token 并点「保存并立即同步」——系统会自动创建/匹配你的私有 Gist（Token 仅保存在你当前浏览器本地，绝不上传公开仓库），做题与阅读位置将在两端自动实时同步！
当前状态：未连接云同步（仅保存在本机浏览器）

方式二：进度码手动导入 / 导出（免 Token 迁移本地进度）

如果你想把之前本地 file:// 网页里的做题进度迁移到线上网址，点「复制本机进度码」，再到线上网址点「粘贴并合并导入」即可。
